# Flanker UI

Flanker UI is a lightweight, reactive UI library for building dynamic web applications with TypeScript.

## Features

- **Reactive Views**: Auto-updating components via `mountView`.
- **State**: Shared reactive state with `createStore` and optional persistence via `persist`.
- **Class Components**: `UiView` with decorators for props, bindings, queries, and events.
- **Forms**: Two-way helpers for inputs, selects, checkboxes, radios, and ranges.
- **Fluent DOM**: Cleaner manipulation via extended `HTMLElement` helpers.
- **VQL**: VQL queries for data.
- **Events**: Declarative event delegation for dynamic content.
- **Utilities**: `debounce`, `throttle`, `escapeHTML`, async `getJSON`, and more.
- **Modular**: Use DOM extensions or other parts standalone.
